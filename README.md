# DevAAR – AAR/log

Personal blog and evolving archive of ideas and systems, built with [Astro](https://astro.build), Notion, Tailwind CSS and Swup.

[**🖥️ Live Site**](https://log.aars.works)

## ⚡ Commands

Tüm komutlar proje kök dizininden (`pnpm` ile) çalıştırılır:

| Command        | Action                                                |
|:-------------- |:------------------------------------------------------|
| `pnpm install` | Bağımlılıkları kurar                                  |
| `pnpm dev`     | Geliştirme sunucusunu `localhost:4321` üzerinde açar  |
| `pnpm build`   | Production build oluşturur (`./dist/`)                |
| `pnpm preview` | Build edilmiş siteyi lokal olarak önizler             |
| `pnpm check`   | Astro type & config kontrollerini çalıştırır          |
| `pnpm format`  | Biome ile kod formatlar                               |
| `pnpm astro`   | Astro CLI komutlarını çalıştırır                      |
