# DevAAR – AAR/log

Este repositorio contiene el código de **AAR/log**, el blog personal y archivo de ideas de DevAAR.

- Framework: [Astro](https://astro.build) + Tailwind CSS  
- Contenido: generado estáticamente desde una base de datos `Blogs` en Notion  
- Sitio en producción: <https://log.aars.works>

Para información técnica actualizada, consulta el `README.md` principal (en inglés / turco).***
