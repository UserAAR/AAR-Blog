# DevAAR – AAR/log

Đây là mã nguồn cho **AAR/log**, blog cá nhân và kho ý tưởng của DevAAR.

- Công nghệ: [Astro](https://astro.build) + Tailwind CSS  
- Nội dung: build tĩnh từ Notion database `Blogs`  
- Site đang chạy: <https://log.aars.works>

Mô tả kỹ thuật chi tiết (tiếng Anh / tiếng Thổ Nhĩ Kỳ) nằm trong `README.md` ở thư mục gốc.***
