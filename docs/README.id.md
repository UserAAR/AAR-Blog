# DevAAR – AAR/log

Repositori ini berisi kode untuk **AAR/log**, blog pribadi dan arsip ide milik DevAAR.

- Framework: [Astro](https://astro.build) + Tailwind CSS  
- Konten: di–generate secara statis dari database `Blogs` di Notion  
- Situs produksi: <https://log.aars.works>

Untuk penjelasan teknis terbaru, silakan lihat `README.md` utama (bahasa Inggris / Turki).***
