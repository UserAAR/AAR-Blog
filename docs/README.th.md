# DevAAR – AAR/log

ไฟล์นี้เป็นเอกสารสั้น ๆ สำหรับโปรเจกต์บล็อกส่วนตัวของ DevAAR ชื่อว่า **AAR/log**  
ไม่ใช่แม่แบบทั่วไปอีกต่อไป แต่เป็นโค้ดที่ปรับแต่งเพื่อใช้กับเว็บไซต์จริงเท่านั้น

- เทคโนโลยีหลัก: [Astro](https://astro.build) + Tailwind CSS  
- แหล่งข้อมูล: ดึงคอนเทนต์จากฐานข้อมูล `Blogs` ใน Notion แบบ Static Generation  
- เว็บไซต์จริง: <https://log.aars.works>

รายละเอียดเชิงเทคนิค (อังกฤษ / ตุรกี) สามารถดูได้ในไฟล์ `README.md` ที่ root โปรเจกต์***
