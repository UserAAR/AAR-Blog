# DevAAR（AAR/log）

このリポジトリは、DevAAR の個人ブログ兼アーカイブサイト「AAR/log」のコードベースです。  
もともとのテンプレート用ドキュメントではなく、現在はこのプロジェクト専用にカスタマイズされています。

- フレームワーク: [Astro](https://astro.build) + Tailwind CSS  
- コンテンツ: Notion の `Blogs` データベースから SSG で取得  
- ライブサイト: <https://log.aars.works>

最新かつ doğru bilgiler için ana `README.md` dosyasına bakabilirsiniz.
