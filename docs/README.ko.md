# DevAAR – AAR/log

이 리포지토리는 DevAAR의 개인 블로그이자 아카이브 사이트인 **AAR/log**의 코드베이스입니다.  
더 이상 범용 템플릿이 아니라, 실제 프로덕션 사이트를 위한 커스텀 프로젝트입니다.

- 기술 스택: [Astro](https://astro.build) + Tailwind CSS  
- 컨텐츠: Notion `Blogs` 데이터베이스에서 SSG 방식으로 가져옴  
- 라이브 사이트: <https://log.aars.works>

최신 기술 설명은 루트 디렉터리의 `README.md` 파일(영어/터키어)을 참고해 주세요.***
